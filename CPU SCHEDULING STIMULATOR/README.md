# CPU Scheduling Simulator

A simple CPU Scheduling Simulator project.

## Project Structure

- `frontend/` — Contains the user interface:
  - `index.html`
  - `style.css`
  - `script.js`
- `main.cpp` — C++ source code for the simulator.

## Features

This project demonstrates CPU scheduling concepts.

## Technologies Used

- HTML
- CSS
- JavaScript
- C++

## How to Use

1. Open the `frontend/index.html` file in a web browser.
2. Enter process details in the interface.
3. Select a CPU scheduling algorithm.
4. View the scheduling result.
